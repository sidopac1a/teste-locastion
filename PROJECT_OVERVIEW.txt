🚀 خطوات النشر:
═══════════════════════════════════════════════════════════════════════════

1. إعداد Firebase:
   $ اذهب إلى https://console.firebase.google.com
   $ أنشئ مشروع → فعّل Authentication → أنشئ Firestore
   $ انسخ الإعدادات إلى .env.local

2. تثبيت الحزم:
   $ cd employee-tracking-app
   $ npm install

3. التشغيل المحلي:
   $ npm run dev
   $ افتح http://localhost:3000

4. النشر على Vercel:
   $ vercel --prod
   $ أو اربط مستودع GitHub مع Vercel
